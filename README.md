# youth-substance-use-dataset-western-uganda
A quantitative dataset of 381 youths aged 18–30 years in Bushenyi District, Western Uganda, covering substance use, associated factors, consequences, health conditions, help-seeking and treatment experiences, and community responses. Collected through a stratified cross-sectional survey conducted between November 2024 and November 2025.
The document contains both the .xlsx (excel) and .sav (SPSS) file. The instrument file was what was used to collect the data and coded in spss format for analysis.
